I'm starting this space to write down what I learn while building data and analytics projects — dashboards, pipelines, and the occasional dead end.

## What to expect

Short, practical posts:

- How I built something, end to end
- What I'd do differently next time
- Notes from internships, hackathons, and coursework

## Why write

Writing forces me to actually understand what I did, instead of just remembering that it worked. A quick example — this is how a code block looks on this site:

```python
import pandas as pd

df = pd.read_csv("resale_values.csv")
df.groupby("model")["price"].mean()
```

You can also link out normally, like to [my projects page](/projects), and it'll pick up the site's styling automatically.
